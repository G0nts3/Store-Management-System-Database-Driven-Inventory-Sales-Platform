The Store Management System is a console-based application designed to simulate real-world retail operations. It allows for efficient management of employees, customers, product inventory, and sales transactions through a structured database backend.

Built with Python and SQLite, the system demonstrates strong backend development practices, including database schema design, object-oriented programming, and transactional data handling.

Key Features:
-Employee and customer management (CRUD operations)
-Product inventory tracking with stock validation
-Sales processing with automatic stock updates
-Persistent data storage using SQLite
-Abstract base classes for scalable system design
-Structured CLI interface for navigation
